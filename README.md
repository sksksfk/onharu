# 온하루

민기가 할아버지께 만들어 드립니다.

[온하루 열기](https://sksksfk.github.io/onharu/)

약 기록, 산책, 가죽공예 작품, 가족 안부를 챙기는 모바일 생활 수첩입니다. GitHub Pages로 화면을 제공하고 Cloudflare Workers + D1이 예약 웹 푸시를 보냅니다.

## 갤럭시에서 화면을 닫은 뒤 알림 받기

1. 일반 Chrome에서 위 주소를 엽니다. 카카오톡 안의 브라우저나 시크릿 모드는 피해주세요.
2. 필요하면 Chrome 메뉴에서 **홈 화면에 추가 / 앱 설치**를 선택합니다.
3. **약 → 이 휴대폰 알림 켜기**를 누르고 알림 권한을 허용합니다.
4. **화면 닫고 시험 알림 받기**를 누른 뒤 홈 화면으로 나가거나 화면을 잠급니다.
5. 약 1~2분 뒤 알림창을 확인하고, 온하루로 돌아와 수신 확인 버튼을 누릅니다.
6. 실제 약봉투·처방전을 확인해 매일의 약 시각을 등록합니다. 서버 기준 시간대는 **Asia/Seoul**입니다.

설치만으로 알림이 켜지지는 않습니다. 다른 휴대폰에서는 별도로 연결해야 합니다.

## 한계와 안전

- 생활 보조 시제품이며 의료기기, 응급 감시, 정시 알람 보장 서비스가 아닙니다.
- 인터넷 연결, 휴대폰 및 Chrome의 알림 허용이 필요합니다. 방해 금지·절전·강제 종료·서버 장애에 따라 지연되거나 누락될 수 있습니다.
- **중요한 약은 휴대폰 기본 알람도 함께 사용하세요.** 알림은 복용 지시가 아닙니다. 이미 먹었는지 헷갈리면 약사에게 먼저 확인하세요.
- 놓친 알림을 오래 뒤에 표시하지 않도록 짧은 만료 시간을 적용했습니다. 정시·정확히 한 번·전달 성공을 보장하지 않습니다.
- 매일 고정 시각의 약만 지원합니다. 격일·필요시 복용과 의료 판단은 지원하지 않습니다.
- 가족 자동 알림·위치 추적·다른 기기로 기록 자동 동기화는 없습니다.
- 무료 범위의 소규모 가족용 구성입니다. 서버는 최대 12개 연결 기기, 기기당 32개 시각으로 제한합니다. 공개 등록 API에 강한 사용자 인증은 없으므로 대규모 공개 서비스나 의료 안전 시스템으로 사용하지 마세요.

## 개인정보

- 약 이름·복용량·먹은 기록·안부·연락처·사진은 해당 브라우저의 localStorage에 남습니다. 암호화 저장이 아니므로 공용 기기 사용은 피해주세요.
- 서버 알림을 켠 경우에만 약 시각, 고정 시간대, 브라우저 푸시 구독 정보, 인증 토큰의 해시와 발송 운영 정보를 D1에 저장합니다.
- 잠금화면에는 약 이름 대신 일반적인 약 확인 안내만 표시합니다.
- 앱의 개인 JSON 백업에 푸시 인증 정보는 넣지 않습니다. 개인 백업과 D1 내보내기 파일은 이 저장소에 올리지 마세요.
- **알림 연결 해제**는 해당 기기의 서버 정보를 삭제합니다. 이미 발송된 메시지는 취소하지 못할 수 있습니다.
- 앱의 **모든 기록 지우기**는 서버 연결 해제를 확인한 다음 기기 기록을 삭제합니다. 이 작업에는 인터넷이 필요할 수 있습니다.
- Worker 코드에서 요청·구독·인증 헤더를 로깅하지 않으며 Worker 로그 수집도 끕니다. Cloudflare 자체 서비스 운영 정보에는 Cloudflare의 개인정보 처리 정책이 적용됩니다.

## 구성

- `index.html`: 화면과 기기 내 생활 기록
- `push-client.js`: 푸시 연결·시각 반영·해제·시험·설치 안내
- `sw.js`: 푸시 수신·알림 표시·정적 화면 오프라인 보조
- `manifest.webmanifest`, `icon-*.png`: 홈 화면 설치 정보
- `worker.js`, `schema.sql`: Cloudflare 예약 발송 서버 소스
- `SERVER-README.md`: 서버 설정과 API 및 검증 범위

GitHub Pages 변경은 화면 파일을 배포합니다. 서버 소스(`worker.js`, `schema.sql`)를 수정하는 것만으로 Cloudflare Worker가 자동 갱신되지는 않습니다. 서버는 별도로 배포해야 하며, 기존 D1과 VAPID 키를 보존해야 합니다.
